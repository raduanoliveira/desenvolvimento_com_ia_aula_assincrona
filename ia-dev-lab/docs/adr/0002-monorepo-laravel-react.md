# 0002. ToDo em monorepo com Laravel e React

## Status

Aceita.

## Contexto

A etapa de contexto pedia um projeto real, não só um script solto. Eu precisava de um exemplo pequeno em que a IA pudesse criar API, tela, testes e convenções.

## Decisão

Eu montei uma lista de tarefas em monorepo: API REST em Laravel de um lado e tela em React com TypeScript e Context API do outro.

## Por quê

Essa é a stack que eu já conheço. Assim eu consigo avaliar o que a IA gera, em vez de aceitar código de uma tecnologia que eu não saberia revisar.

## Consequências

O repositório tem duas pastas de domínio, uma para a API e outra para a tela. A IA precisa respeitar essa separação e não misturar API e tela na mesma pasta.
